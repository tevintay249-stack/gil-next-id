# gil-next-id

Public identifier gateway for GIL permanent Atom IRIs (`https://w3id.org/gil-next/atom/{uuid-v4}`).
Generated by `spine/gateway.sh` in [Raiden](https://github.com/tevintay249-stack/Raiden) from its Spine store: a projection,
never a source of record. Regenerate; don't edit by hand. Each page says whether its Atom is in the selected Core or is a candidate.

`w3id-registration/` holds the draft `ids/gil-next/` files for the w3id.org pull request (not yet submitted).
